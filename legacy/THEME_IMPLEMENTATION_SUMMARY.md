## Ключевые особенности

### 🎨 Цветовая система
- **Технические тона**: Синий (#2563EB), зеленый (#10B981), фиолетовый (#8B5CF6)
- **Семантические цвета**: Success, Warning, Error, Info
- **Специализированные цвета**: Gateway статусы, Signal уровни, Call статусы
- **Адаптивность**: Методы для получения цветов в зависимости от темы

### 📏 Система размеров
- **Стандартизированные отступы**: XS, S, M, L, XL, XXL, XXXL
- **Радиусы скругления**: XS, S, M, L, XL, XXL
- **Размеры иконок**: XS, S, M, L, XL, XXL
- **Специализированные размеры**: Для карточек, индикаторов, прогресс-баров

### 🌈 Градиенты
- **Основные градиенты**: Primary, Accent, Technical, Connection
- **Статусные градиенты**: Success, Warning, Error, Info
- **Специализированные градиенты**: Gateway, Signal, Call статусы
- **Адаптивные градиенты**: Card, Navigation, Chip, Dialog

### 🧩 Переиспользуемые виджеты
- `AppWidgets.gradientCard()` - Карточки с градиентом
- `AppWidgets.gradientButton()` - Кнопки с градиентом и загрузкой
- `AppWidgets.statusCard()` - Карточки статуса
- `AppWidgets.gradientProgressIndicator()` - Прогресс-бары с градиентом
- `AppWidgets.gradientChip()` - Чипы с градиентом
- `AppWidgets.signalIndicator()` - Индикаторы сигнала
- `AppWidgets.connectionIndicator()` - Индикаторы подключения
- `AppWidgets.callStatusIndicator()` - Индикаторы статуса вызова

## Использование

### Быстрый импорт
```dart
import '../theme/app_theme_export.dart';
```

### Примеры использования
```dart
// Карточка статуса
AppWidgets.statusCard(
  title: 'Gateway Status',
  status: 'Connected',
  icon: Icons.wifi,
  statusColor: AppColors.gatewayConnected,
)

// Кнопка с градиентом
AppWidgets.gradientButton(
  text: 'Connect',
  onPressed: () {},
  icon: Icons.wifi,
)

// Индикатор сигнала
AppWidgets.signalIndicator(
  signalLevel: 85,
  showBars: true,
  showPercentage: true,
)
```

### Переключение темы
```dart
final themeService = Provider.of<ThemeService>(context, listen: false);
await themeService.setLightTheme();
await themeService.setDarkTheme();
await themeService.setSystemTheme();
```
