# Рефакторинг gost_simbox_android: От прототипа до MVP

## Обзор

Данный документ описывает рефакторинг проекта `gost_simbox_android` с прототипа до MVP (Minimum Viable Product) на основе наработок из папки `simbox`.

## Архитектура

### До рефакторинга
- Прототип с симуляцией SIP и GSM соединений
- Базовый UI для управления gateway
- Простая архитектура с провайдерами

### После рефакторинга
- Интеграция с реальными Android API через `flutter_tele`
- Полноценная архитектура для SIP-to-GSM gateway
- Расширенная функциональность управления звонками и SMS
- Система статистики и мониторинга

## Ключевые изменения

### 1. Интеграция с реальными API

#### GatewayService
- Заменена симуляция на реальные вызовы Android API
- Добавлена поддержка реальных звонков через `TeleEndpoint`
- Интеграция с системой разрешений Android
- Обработка событий звонков в реальном времени

```dart
// До
Future<void> handleSipCall(String number) async {
  // Симуляция
  await Future.delayed(Duration(seconds: 1));
}

// После
Future<void> makeCall(String number) async {
  final result = await _teleEndpoint.makeCall(number);
  // Реальный вызов через Android API
}
```

### 2. Расширенная конфигурация

#### GatewayConfig
Добавлены новые поля для поддержки расширенной функциональности:

- `autoAnswer` - автоматический ответ на входящие звонки
- `callTimeout` - таймаут звонков
- `enableSms` - включение SMS функциональности
- `enableCallLog` - ведение журнала звонков
- `enableCallForwarding` - переадресация звонков
- `enableCallRecording` - запись звонков
- `enableBlacklist/Whitelist` - черный/белый список номеров
- `emergencyNumbers` - номера экстренных служб

## Сравнение с simbox

### Аналогии с simbox
- **Asterisk** → **SIP клиент** в Android
- **Множественные донглы** → **Один телефон**
- **Web интерфейс** → **Flutter UI**
- **Система ротации SIM** → **Одна SIM карта**
- **Обработка звонков** → **Android Telephony API**

### Упрощения для одного устройства
- Убрана сложная система управления множественными модемами
- Упрощена архитектура для работы с одним устройством
- Сохранена основная функциональность SIP-to-GSM gateway
